# Xartwellixa — неотправленное

Белый психологический хоррор в форме личного дневника. Три записки раскрываются с анимацией. Используется только светлое оформление.

## Запуск

Из этой папки: `node preview.cjs`. Откройте http://127.0.0.1:4173.
Для любого статического хостинга используйте содержимое папки `dist`.

## Музыка

Переданный пользователем MP3 скопирован в `dist/sayo-nara.mp3`. Это Sayo-nara (Slowed + Reverb), оригинальная композиция — Dan Salvato, DDLC OST.
Музыка запускается по нажатию «открыть глаза», затем проигрывается по кругу. В интерфейсе сайта кнопки остановки нет. Браузер и операционная система по-прежнему позволяют пользователю управлять звуком. YouTube и внешний аудиосервис не нужны.

## Файлы

- `dist/index.html` — разметка, ссылки и карточки записок.
- `dist/style.css` — бумага, светлое оформление, анимации и мобильное оформление.
- `dist/app.js` — тексты записок, разворот, копирование Discord ID и музыка.
- `dist/presence.png` — созданная для сайта иллюстрация.
- `dist/sayo-nara.mp3` — предоставленная музыка.

Шрифты загружаются с Google Fonts; предусмотрены системные замены. Системная настройка уменьшения движения отключает анимации.

## Секретный слой

Маленький крестик в конце основной страницы открывает «Оборот листа» через анимацию разрыва бумаги. Три обрывка меняют текст при нажатии. Кнопка «собрать обратно» или Escape возвращает на основную страницу, музыка продолжается. При уменьшении движения переход показывается без анимации. Обе страницы остаются светлыми.

## Память страницы

Визиты, последняя прочитанная записка и число открытий изнанки сохраняются только в localStorage этого браузера. При запрете хранилища эффекты продолжают работать в рамках текущего открытия. После закрытия записка показывает ответ на обороте. Четыре отдельные таблетки скрываются со второго открытия изнанки, оставляя буквы. Удерживание пустого поля (мышь, касание или пробел) проявляет нижний текст; отпускание возвращает бумагу. Последний лист появляется через 3,2 секунды присутствия в нижней области страницы.
